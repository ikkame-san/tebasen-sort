# 手羽セン楽曲ソート

手羽先センセーションの好きな曲を選び、自分のランキングを作る非公式ファンサイトです。「デビルアンセムソート」を参考に作成しました。

## 起動

親フォルダーの「起動.cmd」を開き、http://127.0.0.1:4180 でグループを選べます。Node.js 20.9以上が必要です。画像は同梱済みなので、起動のために npm install は必要ありません。

このフォルダーだけで起動する場合:

```powershell
node scripts/serve.mjs
```

単独起動では http://127.0.0.1:4182 を開きます。ES Modulesを使うため、index.htmlの直接ダブルクリックでは起動できません。

## 機能

- 曲名検索、公開年の絞り込み、曲の追加、ランキング対象の選択
- リミックスの表示切替（初期値オフ）。初期表示68曲、オンで69曲
- 上位15曲・25曲・全曲、または任意の順位数を指定
- 2曲比較、3〜4曲の順番選択、30回分の戻る操作、途中保存と再開
- ジャケット入りPNGの保存と共有、結果リンク・テキストのコピー、Xへの共有
- 確認できた公式MV・ダンス・ライブ・曲別ダイジェスト映像の表示。未対応曲はYouTube検索
- 「ネオンテトラ」の映像リンクはXの公式投稿へ移動
- スマートフォン対応、独立したlocalStorageキー

## 曲目

2026-10-08に動画を再確認。69曲、公式動画61曲。ドリーミュージック19作品、TuneCore公式配信11作品、Apple Musicの初期アルバム・「#テバサキレシピ」、公式YouTubeプレイリストを照合しています。2026-10-08には公式チャンネルの公開動画365件を全4ページにわたって取得し、採用した61曲の動画それぞれの投稿元・曲名・公開日を確認しました。公式サイトtebasen.comがメンテナンス中のため、公式レーベルと配信情報で補っています。

再録、リマスター、予科生版、短縮版はまとめ、インスト・カラオケ・テレビサイズは除外しています。別言語、リミックス、アコースティックなどの別アレンジは別曲です。「やるっきゃない！」の年を含む正式タイトルは個別に掲載しています。「Opening SE」はソート対象から除外しています。DJ連続ミックス全体、コンサート名、個人のソロ曲は含めていません。

音源未確認で公式動画を確認できた「オーダーメイド」「恋中毒」「君色限定」「絶対値は∞」「きみがとまんないっ!!!」「≫空色≪スタートライン」「Colorful Days」も掲載しています。これらの年は公式動画の公開年です。「ネオンテトラ」はWEBザテレビジョンのライブレポートで確認した2026-09-22の初披露日を使っています。これらの曲のジャケットは音符表示です。ほかの曲の日付は確認できた収録作品の最も早い日付で、初披露日を保証するものではありません。見つからない曲はUIから追加できます。

動画はMV、ダンス動画、ライブ映像の順で優先し、同種なら新しい公開動画を使用します。「LEGIT」は同曲を使用した公式公演ダイジェストを「ダイジェスト映像」として掲載しています。Shorts、告知、メイキング、曲を特定できない公演全体の動画は曲へのリンクに使いません。

曲別の根拠URLはsongs.jsのsources、ジャケットの元URLはartworkSource、動画の参照元はvideo.sourceに保持しています。公式ページ内の重複、誤記、全角半角の表記揺れを整理しています。「証 fear.Ayasa」を「証 feat.Ayasa」に補正しています。

## 画像と保守

jackets内のWebPは256pxで同梱しています。画面もPNG保存も同一オリジンの画像を使います。音源・歌詞は同梱しません。カタログの手動更新はsongs.jsを編集し、既存のIDを維持してください。画像を再取得する場合のみ依存関係をインストールします。

```powershell
npm ci
node scripts/build-jackets.mjs
npm run check
npm test
```

静的ホスティングへはindex.html、app.js、engine.js、songs.js、jackets.js、catalog.js、styles.css、favicon.svg、jackets/を配置すれば動きます。

## 保存と共有

選択・途中結果・追加曲・名前はブラウザ内に保存します。両グループの保存キーは別です。共有リンクのURLフラグメントには順位、曲名、任意の名前、作成日、対象曲数が入ります。ローカル起動中のURLは他の端末から開けません。公開後は公開URLの結果リンクを共有できます。

本サイトは非公式で、各グループと関係各社とは関係ありません。
